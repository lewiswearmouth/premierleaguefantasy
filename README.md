# Premier League Fantasy Trophy

A simple website made for my personal Fantasy Premier League group to track standings, league competition, and crown the season champion.

🌐 Live Site: https://lewiswearmouth.github.io/premierleaguefantasy/

## Overview

This project serves as a digital trophy case and league hub for my fantasy league, giving everyone a clean place to view standings and follow the competition throughout the Premier League season.

## Features

- Fantasy league standings
- League-focused UI
- Responsive design
- GitHub Pages deployment
- Lightweight frontend implementation

## Tech Stack

- HTML
- CSS
- GitHub Pages

## Purpose

Built as a fun personal project combining sports, competition, and frontend web development.
